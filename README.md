## Projects

### Completed

**[Customer Churn Prediction](https://github.com/madhushankarkr-cmd/customer-churn-prediction)** · `Python` `Scikit-learn` `XGBoost` `Streamlit`
End-to-end ML pipeline predicting telecom customer churn on the IBM Telco dataset (7,032 customers, 19 features). Covers cleaning, EDA, preprocessing, and comparison of Logistic Regression, Random Forest, and XGBoost. The best model (Logistic Regression, ROC-AUC 0.836) is deployed as an interactive Streamlit app. [Live demo](https://customer-churn-prediction-fcwb7heyjeyuwziwhxcnir.streamlit.app/)

**[Wildlife Guardian AI](https://github.com/madhushankarkr-cmd/Wildlife-Guardian-AI)** · `Python` `YOLOv8` `Computer Vision`
Computer vision system that detects animals in images, identifies environmental threats, and produces a Wildlife Risk Score (0-100) with an explanation. Built for the Global AI Hackathon.
